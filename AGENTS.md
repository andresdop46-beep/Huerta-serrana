# Reglas del proyecto Huerta Serrana
- Sitio estático de 4 páginas: index.html, catalogo.html, productores.html, contacto.html.
- PROHIBIDO usar JavaScript, Bootstrap, Tailwind ni ningún framework CSS o JS.
- PROHIBIDO cargar recursos externos: ni CDN, ni Google Fonts, ni analíticas.
- Usar HTML5 semántico estricto (header, nav, main, section, article, aside, footer), un solo h1 por página sin saltar niveles.
- Metodología CSS BEM (.bloque, .bloque__elemento, .bloque--modificador) sin estilos en línea ni !important.
- Usar EXCLUSIVAMENTE las variables CSS definidas en css/tokens.css para colores, fuentes, espaciados y radios.
- Usar únicamente los datos reales del Anexo B (productos, precios, productores y cestas). No inventar contenido.
